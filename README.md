# Creador-de-video-para-redes-revit-estructural

Herramienta para generar un video vertical de unos 60 s (Instagram, TikTok, Facebook) en el que un
modelo estructural de Revit 2025 se construye por etapas: armado, piedras de la mampostería y
blocks colocados hilada por hilada, mientras la cámara gira. Funciona con Dynamo (nodos Python con
CPython3) y Python en Windows.

Instrucciones completas en [LEEME.md](LEEME.md).
