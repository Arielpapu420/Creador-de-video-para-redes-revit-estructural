# Creador-de-video-para-redes-revit-estructural

Herramienta para generar un video vertical de unos 30 s (Instagram, TikTok, Facebook) en el que un
modelo estructural de Revit 2025 se construye por etapas mientras la cámara gira. Funciona con
Dynamo (nodo Python con CPython3) y Python en Windows.

Instrucciones completas en [LEEME.md](LEEME.md).
